# M0-07 — On-device AI (Foundation Models)

**Question:** can iBoard use Apple's on-device model for proofread/rewrite (D-16)?

**Method:** throwaway app on the owner's iPhone 12 (iPhone13,2, iOS 27.0) printed `SystemLanguageModel.default.availability`
and attempted one `LanguageModelSession().respond` (console captured with `devicectl --console`), 2026-10-26.

**Result:** `unavailable(.deviceNotEligible)`. The model reports 24 supported languages, but the iPhone 12 is not an
eligible device, so no latency could be measured.

**Not tested:** calling from the keyboard extension; memory/latency on an eligible device (none available to us);
Hinglish quality.

**Conclusion / impact:** **fails on the reference device (D-05).** Any AI feature would be unavailable on iPhone 12
and would have to be an optional, availability-gated extra on newer devices, designed to be absent without notice.
D-16 stays as written: ships post-v1 only if a later spike on an eligible device passes (extension feasibility and
memory first). No v1 work depends on it.
